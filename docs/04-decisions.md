## A. Решено (автор — ИИ-агент, одобрено заказчиком 25.11.2026)

### A1. Технологии
Python 3.12 + FastAPI, PostgreSQL 16, Redis не требуется в MVP (advisory locks в БД),
worker с лидерством через advisory lock, Docker Compose. **Проверено в бою**:
VK-бот отвечает в группе 243684200, 136 тестов, 246 cmd/s.

### A2. Формулы
Строковые формулы в `formulas` + безопасный AST-вычислитель (белый список операторов).
Текущие формулы кода-заглушки не используются — все расчёты в коде ядра с параметрами из `config_params`.

### A3. Экономика
- Внутренний рынок Эонов — **ордерная книга** со сведением worker'ом, сделка по цене мейкера,
  частичное исполнение; защита — отклонение от ориентира (`market.max_deviation_pct=50`).
- Аукцион — ставки + выкуп; ставки резервируют Кванты; отмена без ставок → возврат через 20 мин.
- Передача ценных (≥5000 Квантов или rare+) — с подтверждением получателя; инвентарь получателя
  полон → активы возвращаются отправителю.
- Комиссии/налоги: аукцион 1% с продавца, налог рынка Эонов 10% с продавца (заложено в параметрах,
  включение — правкой `config_params`).

### A4. Стартовый баланс v1 (все значения в `config_params`, правятся из админ-панели без кода)
| Параметр | v1 |
|---|---|
| Корабль стартовый | прочность 100, топливо 50, атака 5 |
| События | цена топлива 1–4, опасность 1–10 |
| Экспедиция | очередь 10 событий, задержка возврата 60 с |
| fuel_empty | +1 поломка |
| Поражение | +1 поломка, потеря 10–30% добычи (только `losable_on_defeat`) |
| Отступление | шанс 60%, урон 30%×10, поломка 10% |
| Бой | разброс урона ±10%, расходников за ход 2 |
| Модули | пороги уровней 0/50/150/300/500 |
| Сброс сборки | триний 5 × (число сбросов + 1) |
| Крафт | 1 слот (+1 подписка), возврат при отмене 50% |
| Инвентарь/склад | 30 (+50% подписка) / 20 |
| Лимиты лотов | 5 (10 с подпиской), длительность 24 ч |
| Подписка | 7 дн = 99 Эонов, 30 дн = 249 Эонов |
| Рынок Эонов | ориентир 1000 Квант/Эон, ордер 1–1000 Эонов |
| Имена | 3–24 символа, паттерны админ-имитации запрещены |
| Подписка | 1 персонаж на аккаунт; прогресс обучения общий |

Контент v1: 4 фракции, 8 событий (2 боевых), 3 противника (normal/dangerous/elite),
4 модуля (2 навыка/2 способности), 3 рецепта, цепочка из 4 заданий, 2 подписки, пак Эонов.
