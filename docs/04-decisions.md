Статус каждого пункта: `[открыто]` — вопрос из ТЗ, требует решения заказчиком; `[предложение]` — позиция ИИ-агента, вынесена на согласование (по инструкции ТЗ не принимается как правило без подтверждения).

## A. Технологические `[открыто]` → `[предложение]`

| № | Вопрос | Предложение агента |
|---|---|---|
| A1 | Технологический стек, инфраструктура, СУБД, очереди, планировщик (ТЗ, «Открытые решения №1») | Python 3.12 + FastAPI, PostgreSQL 16, Redis (блокировки/кэш/rate limit), ARQ + собственный планировщик по таблице `timers`, Docker Compose на VPS |
| A2 | Вычисление формул без правки кода | Строковые формулы в `formulas` + безопасный AST-вычислитель с белым списком операторов. Альтернатива: параметрические шаблоны формул (без свободного кода) — безопаснее, менее гибко |
| A3 | Модель внутреннего рынка Эонов (ТЗ №13) | Ордерная книга buy/sell со сведением worker'ом; курс-ориентир, спред и лимиты — `market_config`; защита: капы на размер/частоту ордеров + допустимое отклонение от скользящего ориентира |
| A4 | Аукцион (тип лотов) | Классический аукцион со ставками + мгновенный выкуп (buyout); срок лота из config |

## B. Открытые числовые значения ТЗ — складывать в `config_params` со стартовыми заглушками `[открыто]`

Боевые формулы и шкалы опыта (ТЗ №2); стартовый баланс: топливо, цены, таймеры, вероятности, потери при поражении (№3); разграничение дроп/waiting (№4 — механика зафиксирована в архитектуре, пороговые значения открыты); ремонт/восстановление прочности в космопорту (№5); формула сложения бонусов подписки (№6 — зафиксированы кап 95% и затухание, сама формула открыта); лимиты/комиссии прямых передач + поведение при переполнении инвентаря получателя (№7); базовые производственные слоты и расширение (№9); минимальный состав контента MVP (№10).

## D. Допущения агента, требующие подтверждения `[предложение]`

| № | Допущение | Обоснование / альтернатива |
|---|---|---|
| D1 | Один персонаж на аккаунт в MVP | ТЗ не уточняет; мультиперсонажность усложняет командный lock (ключ — character_id, проблем нет), но расширяет объём UI. Легко добавить позже |
| D2 | Склад — один на персонажа, слоты расширяются | ТЗ: склад в космопорте, недоступен в экспедиции; число слотов — №7 B |
| D3 | Очередь событий экспедиции генерируется при старте целиком (seeded) | ТЗ: «случайно сформированная последовательность», игрок не выбирает; генерация на лету эквивалентна при seeded RNG и даёт воспроизводимость для аудита |
| D4 | «Глубина экспедиции» = счётчик пройденных событий | ТЗ: глубина не влияет на сложность; используется для аналитики/прогресса |
| D5 | Смена фракции: стартовое отрицательное значение новой репутации, конкретное число — config; cooldown 30 дней заглушка | ТЗ фиксирует механику, не числа |
| D6 | Враги MVP используют weighted-выбор действия; пассивы/слабости только у elite/boss (по ТЗ) — поведенческий граф готовит конструктор механик | ТЗ, «Боевая система» и «Будущие системы» |
| D7 | Уведомления группируются по принципу: все завершения крафта за окно N минут — одним сообщением; уникальные предметы/платежи — отдельно | ТЗ требует объединения и отдельных важных; конкретное окно — config |
| D8 | Имя персонажа: длина 3–24 символов, blacklist регулярных выражений (оскорбления, имитация администрации `[Admin]`, `@` и т.п.) + постмодерация с forced rename | ТЗ требует проверки, параметры не заданы |
| D9 | VK: Long Poll для MVP; Callback API — как масштабная опция без смены ядра | Проще эксплуатация на старте; лимиты учитываются диспетчером outbox в обоих случаях |
| D10 | Продление/наложение подписок складывается по оставшемуся времени; бонус редкого дропа считается с затуханием от числа активных бонусов | ТЗ: бонусы складываются, каждый следующий слабее, кап 95%; формула — №6 B |

## E. Осознанно вне MVP (по ТЗ) `[вне MVP]`

PvP, войны фракций, совместные экспедиции и встречи игроков, побег противников, игроки-лидеры фракций, разведка, расширенная защита корабля, визуальный конструктор механик (поле `behavior` под JSON-граф заложено). Telegram-адаптер: интерфейс адаптера готовится в этапе 0–1, реализация — отдельным этапом по запросу.
